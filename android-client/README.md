# پولاریس اندروید

APK از [Releases](https://github.com/kamkazi1297/polaris/releases/latest) — فایل `Polaris.apk`.

نصب از منابع ناشناس را روشن کنید، کانفیگ را وارد کنید، تست دیلی بگیرید، **وصل شو** را بزنید و دسترسی VPN ویندوز/اندروید را تأیید کنید.

پروتکل‌های تونل روی اندروید: VLESS، VMess، Trojan، Shadowsocks. Hysteria2 / TUIC / WireGuard فقط پارس و تست می‌شوند؛ برای وصل شدن آن‌ها از نسخه ویندوز استفاده کنید.
