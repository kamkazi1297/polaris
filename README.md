# پولاریس

کلاینت پروکسی ویندوز (شبیه v2rayN) + بازرس کانفیگ در مرورگر.

## دانلود ویندوز

از صفحهٔ [Releases](https://github.com/kamkazi1297/polaris/releases/latest) فایل **`Polaris-windows-x64.zip`** را بگیرید.

1. زیپ را باز کنید و `Polaris.exe` را اجرا کنید.
2. اگر SmartScreen آمد: **More info → Run anyway** (فایل امضا نشده است).
3. بار اول هستهٔ رسمی **Xray** (یا **sing-box** برای Hysteria2 / TUIC / WireGuard) از گیت‌هاب دانلود می‌شود.
4. **ورود کانفیگ** یا **کلیپ‌بورد** — لینک، JSON نپسترنت، Clash، Xray یا آدرس سابسکریپشن.
5. **تست دیلی** — پینگ TCP + مکان واقعی سرور. اگر سرور ایران باشد برچسب **مشکل‌دار** می‌خورد (از فیلتر رد می‌شود ولی مکان عوض نمی‌شود).
6. **وصل شو** — پروکسی سیستم ویندوز روی `127.0.0.1:10809`.

### چه چیزی نشان داده می‌شود

| ستون | معنی |
| --- | --- |
| نوع | مثلاً `VLESS · Reality` |
| وضعیت | سالم / مشکل‌دار / بدون پاسخ |
| دیلی | فقط تست تأخیر TCP |
| مکان | کشور و شهر سرور |
| امنیت | بالا / متوسط / پایین + دلیل |

تنظیمات هسته: Mux، Fragment، DNS، دور زدن ایران/LAN، تبلیغات، sniffing، UDP، اثر انگشت.

### محدودیت

- حالت **system proxy** است، نه TUN کامل. بعضی برنامه‌ها پروکسی سیستم را رعایت نمی‌کنند.
- تست دیلی handshake کامل پروتکل نیست؛ مکان، مکان خود سرور است نه IP خروجی داخل تونل.

سورس ویندوز: [`win-client/`](win-client/).

## بازرس وب

همین ریپو یک بازرس مرورگر هم دارد: لینک را می‌چسبانید، نوع / امنیت / مکان را می‌بینید، فقط تست دیلی می‌گیرید، و JSON را برای کلاینت واقعی کپی می‌کنید. ترافیک سیستم را تونل نمی‌کند.
