# پولاریس

کلاینت پروکسی برای **ویندوز** و **اندروید** (شبیه v2rayN / NapsternetV) + بازرس کانفیگ در مرورگر.

## دانلود

از صفحهٔ [Releases](https://github.com/kamkazi1297/polaris/releases/latest):

| فایل | برای |
| --- | --- |
| **Polaris-Setup.exe** | ویندوز ۱۰/۱۱ ۶۴بیت — این را نصب کنید |
| Polaris-windows-x64.zip | نسخه قابل‌حمل؛ کل پوشه را Extract کنید |
| **Polaris.apk** | اندروید |

### ویندوز باز نمی‌شود؟

فایل داخل زیپ را مستقیم اجرا نکنید. **Setup** را بگیرید. اگر SmartScreen آمد: More info → Run anyway.

### اندروید

نصب از منابع ناشناس را اجازه دهید. منوی سه‌نقطه:

- ساب‌لینک‌ها + به‌روزرسانی
- حذف کانفیگ تکراری
- مرتب‌سازی معتبر / دیلی / نام
- تنظیمات (DNS، Mux، Fragment، دور زدن ایران/LAN)

## کارهایی که برنامه می‌کند

1. ورود لینک، JSON نپسترنت، Clash، Xray یا آدرس سابسکریپشن
2. نوع کانفیگ (مثلاً `VLESS · Reality`) و گزارش امنیت
3. **فقط تست دیلی** + مکان واقعی سرور
4. اگر سرور ایران باشد → **مشکل‌دار** (از فیلتر رد می‌شود ولی مکان عوض نمی‌شود)
5. وصل شو: ویندوز = پروکسی سیستم `127.0.0.1:10809` — اندروید = VPN سیستم

### محدودیت

- ویندوز حالت **system proxy** است نه TUN کامل
- تست دیلی handshake کامل پروتکل نیست
