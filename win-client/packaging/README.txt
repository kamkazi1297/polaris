Polaris for Windows
===================

اگر با کلیک روی Polaris.exe چیزی باز نشد:

1. کل پوشه را از ZIP خارج کنید (روی خود فایل zip دابل‌کلیک نکنید).
2. Start-Polaris.bat را اجرا کنید — فایل را از حالت Block ویندوز در می‌آورد.
3. یا روی Polaris.exe راست‌کلیک → Properties → اگر Unblock بود تیک بزنید → OK.
4. اگر SmartScreen آمد: More info → Run anyway.

نسخه نصب‌شونده: Polaris-Setup.exe را اجرا کنید.

کانفیگ را بچسبانید، تست دیلی بگیرید، بعد وصل شو.
