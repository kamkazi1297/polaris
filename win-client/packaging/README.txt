Polaris — ویندوز ۶۴ بیت
========================

اگر روی Polaris.exe کلیک کردید و هیچی باز نشد:

1) فایل را از داخل ZIP اجرا نکنید.
   روی zip راست‌کلیک → Extract All → بعد Start-Polaris.bat را بزنید.

2) بهتر است Polaris-Setup.exe را نصب کنید (میانبر دسکتاپ می‌سازد).

3) SmartScreen ویندوز: More info → Run anyway

4) ویندوز باید ۶۴ بیتی و ویندوز ۱۰ یا ۱۱ باشد.

بعد از باز شدن:
- ورود کانفیگ یا ساب‌لینک https
- تست دیلی (مکان واقعی سرور)
- اگر ایران باشد = مشکل‌دار
- وصل شو = پروکسی سیستم روی 127.0.0.1:10809
